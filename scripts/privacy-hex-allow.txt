# Explicit allowlist for the long-hex check. Comments explain every rule.
# Exact tokens are public values already in this repo. Field and label rules
# allow a class of public ids. They do not allow order_hash, salt, or key.
#
# Obvious fakes are not listed here. The checker allows them itself:
# one repeated nibble, 0x0 through 0x10, dead/beef/cafe/c0ffee/deadbeef,
# a body made only of 0123456789abcdef or abcdef0123456789, and the dummy
# marker bb22cc33dd44ee55ff6677889900.
