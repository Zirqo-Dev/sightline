# Exact tokens are public values already in this repo. A field rule allows a
# whole JSON value of one shape. A path rule is limited to that file. They do
# not allow order_hash, salt, or key.
#
# Obvious fakes are not listed here. The checker allows a whole token that is
# one repeated nibble, 0x0 through 0x10, dead/beef/cafe/c0ffee/deadbeef,
# only 0123456789abcdef or abcdef0123456789 repeated, the dummy marker as the
# entire value, or the full sequential fixture pattern. A substring is not enough.
